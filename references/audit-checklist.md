# Website and Automation Audit Checklist

Run during research. Mark each: OK / ISSUE (with evidence + source) / N/A / NOT CHECKED. Never report an issue you didn't actually observe.

## A. Findability (Google / Maps)
- [ ] Search "[service] [town]" and "[service] near [landmark]" - their map-pack and organic position; who's top 3
- [ ] Google Business Profile: website link present? hours correct? categories? photos recent? posts?
- [ ] Review count + rating vs top competitor; owner replies to reviews?
- [ ] Search brand name - does their site rank first, or Facebook/Zomato/Yelp/directories?
- [ ] Service-area / location pages exist? (local)
- [ ] SaaS: ranks for "[category] software", "[competitor] alternative", "[product] vs [competitor]"?

## B. First impression (mobile, 5 seconds)
- [ ] Site exists at all? HTTPS? Loads under ~3s on mobile? (PageSpeed Insights if available)
- [ ] Clear headline: what, for whom, where
- [ ] Primary CTA visible without scrolling (Call / Book / Order / Get Quote / Start trial)
- [ ] Click-to-call phone number on mobile (local)
- [ ] Looks dated? (old copyright year, Flash-era design, stock photos, broken images)
- [ ] Menu/prices as readable text, not PDF/image (cafes/restaurants)

## C. Conversion
- [ ] Can a customer book / order / request a quote without calling?
- [ ] Contact form works? How many fields? Confirmation message?
- [ ] Pricing or "starting from" shown? (local services: even ranges help)
- [ ] Social proof on site: reviews, testimonials, before/after, logos, case studies
- [ ] Trust: licenses, insurance, guarantees, years in business, team photos
- [ ] SaaS: signup steps count, free trial clarity, demo booking instant calendar?, pricing clarity, comparison pages

## D. Speed of response / automation gaps
- [ ] After-hours: what happens to calls, forms, DMs? (only test if user allows; otherwise infer and label as inference)
- [ ] Reviews mentioning "no answer", "never called back", "slow reply", "couldn't book"
- [ ] Booking via DM/WhatsApp/phone only
- [ ] No reminders (no-shows mentioned in reviews)
- [ ] No review-request system (low review count vs customer volume)
- [ ] No email/SMS/WhatsApp list or loyalty for repeat customers
- [ ] SaaS: generic or no onboarding emails (sign up with a test email only if user permits), no chat/support bot, manual lead routing signals (hiring SDR/ops)

## E. Freshness and activity
- [ ] Last social post date; last blog post; last site update
- [ ] Seasonal content current? (e.g. lawn: spring cleanup; HVAC: AC tune-up)
- [ ] Wrong/outdated info: hours, prices, menu, staff, addresses

## F. Technical basics
- [ ] Broken links / 404s on main nav
- [ ] Missing meta title/description (shows badly in Google)
- [ ] No favicon, no OG image (looks bad when shared)
- [ ] Mixed content / SSL warnings

## Prioritise
For each ISSUE, score 1-5:
- **Money**: how directly it loses customers/revenue
- **Obvious**: will owner instantly get it and feel it?
- **Fixable**: can sender fix it with website/automation?

Top total = primary hook. Second = backup hook / follow-up #1. Third = follow-up #2 or P.S.

## Soft-estimate formulas (always label "rough estimate")
- Missed calls: missed per week x % who don't call back (~60-80%) x close rate x avg ticket
- Aggregator commission: daily orders x avg order x commission %
- No-shows: weekly no-shows x avg service price
- SaaS signups: monthly visitors x conversion lift x trial-to-paid x ARPA
Use only inputs you found or common industry ranges; state assumptions in the notes, keep the email phrasing soft ("even 2 jobs a week...").
